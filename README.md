# Terraform en GCP

Este es un repositorio donde voy a ir subiendo codigos que he realizado con Terraform en GCP. Voy a estar subiendo los que ya tengo realizados e iré subiendo aquí cualquier nueva infraestructura que vaya creando también.

## Tecnologías
- Terraform v1.15.8
- Google Cloud Platform (GCP)

## Requisitos
- Necesitas tener instalado Terraform.
- Una cuenta en GCP para poder ver los cambios.
- El gcloud CLI configurado en tu ordenador para poder aplicar los cambios con Terraform en tu proyecto de Google Cloud.

## Uso
Entra en cada carpeta de ejercicio y ejecuta:
```bash
terraform init
terraform plan
terraform apply
terraform destroy
```
